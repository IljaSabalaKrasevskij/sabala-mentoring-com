# Start hier: deine Skill-Pakete

Sechs Pakete mit je drei Skills für Claude. In den Skills stehen die Regeln, nach denen ich selbst schreibe, gestalte, recherchiere und baue.

Ein Skill ist eine Anleitung, die Claude liest, wenn sie gebraucht wird. Du musst dir nichts merken: Bittest du Claude um einen Newsletter, nimmt es den passenden Skill von selbst.

## Was in diesem Ordner liegt

| Paket | Skills |
|---|---|
| Skill-Paket Texte | menschlich-schreiben, einfach-erklaeren, newsletter-schreiben |
| Skill-Paket Design | schoen-gestalten, bilder-mit-stil, vor-dem-livegang |
| Skill-Paket SEO und KI-Suche | themen-finden, seo-seite, ki-suche |
| Skill-Paket Marktrecherche | mitbewerber-pruefen, zielgruppe-schaerfen, quellen-pruefen |
| Skill-Paket Social Media | beitrag-schreiben, karussell-planen, reel-skript |
| Skill-Paket Entwicklung | tokens-sparen, sicher-bauen, sauber-ausliefern |

In jedem Paket-Ordner liegt eine eigene Datei „00 Start hier“. Dort steht zu jedem Skill, wofür du ihn nutzt, mit fertigen Aufträgen und einem Vorher und Nachher.

## Mein Rat

Fang mit einem Paket an. Nimm das, das zu der Aufgabe passt, die du am häufigsten erledigst. Die anderen kommen dazu, wenn du merkst, dass dir etwas fehlt.

Warum nur drei Skills je Paket? Claude entscheidet bei jedem Auftrag selbst, welcher Skill passt. Drei klar getrennte Skills greifen zuverlässig. Viele ähnliche kommen sich in die Quere.

## So geht es weiter

1. Lies „01 Installation“. Dort steht, wie du die Skills in Claude Code und in der Claude-App einrichtest.
2. Öffne den Ordner deines ersten Pakets und lies dort „00 Start hier“.
3. Gib Claude einen der fertigen Aufträge und schau dir das Ergebnis an.

Updates bekommst du per Mail. Was sich geändert hat, steht in `AENDERUNGEN.md`.
