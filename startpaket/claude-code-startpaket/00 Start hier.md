# Claude-Code-Startpaket

Schön, dass du da bist. Dieses Paket bringt dich durch deine erste Woche mit Claude Code. Vorwissen brauchst du keins.

Stand: November 2026


## Was drin ist

- **01 Installation.md:** Claude Code auf Mac oder Windows einrichten, Schritt für Schritt, dazu Hilfe bei den häufigsten Fehlern.
- **02 Befehle.md:** die Befehle und Tasten, die du am Anfang wirklich brauchst.
- **03 Die CLAUDE-Datei.md:** wie du Claude einmal sagst, wer du bist und wie es arbeiten soll.
- **04 Zehn Skills.md:** zehn Erweiterungen, die ich selbst nutze, jeweils mit dem Befehl zum Installieren.
- **vorlagen/projekt/CLAUDE.md:** Vorlage für einen Projektordner.
- **vorlagen/global/CLAUDE.md:** Vorlage für Regeln, die in all deinen Projekten gelten.

Alle Dateien sind Markdown, das Format, in dem auch Claude Code liest und schreibt. Du öffnest sie mit jedem Texteditor, auf dem Mac zum Beispiel mit TextEdit, auf Windows mit dem Editor.


## In dieser Reihenfolge

1. Installier Claude Code mit der Anleitung in 01.
2. Leg einen Ordner für dein erstes Projekt an, zum Beispiel „meine-webseite“ in deinem Ordner Dokumente.
3. Kopier die Datei CLAUDE.md aus „vorlagen/projekt“ in diesen Ordner und füll die Stellen in [eckigen Klammern] aus.
4. Starte Claude Code in dem Ordner und gib ihm eine erste Aufgabe. Drei Beispiele stehen unten.
5. Läuft das, nimm dir einen Skill aus 04 dazu. Einer reicht für den Anfang.


## Drei Aufgaben für deine erste Stunde

Schreib so, wie du mit einem Menschen sprichst. Ganze Sätze reichen, Fachwörter brauchst du nicht.

1. „Lies die CLAUDE.md und sag mir in drei Sätzen, was du über mich und dieses Projekt weißt.“
2. „Leg eine Datei ideen.md an und sammle darin zehn Themen für meinen Newsletter.“
3. „Bau mir eine einfache Webseite in einer einzigen Datei index.html: oben mein Name, darunter drei Abschnitte über mein Angebot.“

Bevor Claude eine Datei anlegt oder ändert, fragt es dich. Lies kurz, was es vorhat, und sag dann ja. Die fertige index.html öffnest du per Doppelklick im Browser.
