### 4.3 Atemberaubende Gäste-Intros

**Philosophie:** Ein gutes Intro zeigt dem Gast: "Ich kenne dich wirklich." Nicht die Wikipedia-Bio, sondern das, was ihn besonders macht.

**Intro-Struktur (60-90 Sekunden gesprochen):**
```
[KONTEXT: Warum dieser Gast jetzt, zu diesem Thema]
  → "Was uns heute verbindet ist die Frage: [Kernthema der Episode]"

[WER: Die eine Sache, die der Gast anders macht als alle anderen]
  → Nicht: "XY ist Coach mit 10 Jahren Erfahrung..."
  → Sondern: "XY hat etwas entdeckt, das die meisten Unternehmer übersehen..."

[BELEG: Konkrete Zahl, Geschichte, oder Leistung]
  → "Er/Sie hat [konkretes Ergebnis] — und heute erklärt er/sie wie."

[ÜBERGANG: Neugier-Aufbau]
  → "Was mich an unserer Vorbereitung am meisten überrascht hat ist..."
```

**Gäste-Intro-Workflow (mit Claude Code):**
```
1. Gast-Recherche: LinkedIn, Website, bisherige Interviews, Bücher
2. Claude Code: "Erstelle ein 90-Sekunden-Intro für [Gast] basierend auf 
   diesen Quellen — emotional, präzise, wertschätzend"
3. Draft reviewen und persönliche Note hinzufügen
4. Vorlesen und Timing testen (sollte sich natürlich anfühlen)
5. Intro dem Gast vorab zeigen → er/sie fühlt sich gesehen
```

**Notiz:** Den Gast das Intro vorab zu zeigen ist ein starker Differenziator.
Kaum ein Podcaster macht das — und es bindet den Gast emotional an dich.

### 12b.1 Transkript-Extraktion Workflow

**Ziel:** Jede Episode hat automatisch ein gespeichertes Transkript lokal + in NotebookLM

**Option A: Riverside (empfohlen)**
```
→ Riverside generiert automatisch Transkript während der Aufnahme
→ Nach dem Schnitt: Transkript als .txt / .srt exportieren
→ Ablage: EP0XX/05_Show_Notes/Transkript_EP0XX.txt
→ Kopie → NotebookLM hochladen
```

**Option B: Buzzsprout (nach Upload)**
```
→ Buzzsprout hat eingebaute Transkription (kostenpflichtig)
→ Alternativ: Whisper AI (OpenAI, kostenlos/lokal) via Claude Code
→ Befehl: whisper audio.mp3 --language de --output_format txt
```

**Option C: Automatisierung via Claude Code (Skill)**
```
→ Skill: "Transkribiere Episode" → Riverside-MP3 → Whisper → .txt → ablegen
→ Gleichzeitig: Show Notes entwurf aus Transkript generieren
→ NotebookLM-Quellen automatisch updaten
```

### 12b.2 Transkript-Nutzung (nach Speicherung)

```
Transkript vorhanden → ermöglicht:
  ✓ NotebookLM-Quellen stets aktuell

  ✓ Show Notes automatisch entwurfen
```
