# Draco-Entpacker

Die drei Dateien in diesem Ordner (`draco_decoder.js`, `draco_decoder.wasm`, `draco_wasm_wrapper.js`) entpacken
das 3D-Modell von Mooni auf der Seite `/claude-code/skill-paket`. Sie liegen hier, damit der Browser dafür keine
Anfrage an einen fremden Server schickt.

- Herkunft: Draco von Google, unverändert aus dem Paket `three` (`examples/jsm/libs/draco/gltf`)
- Lizenz: Apache-Lizenz 2.0, https://www.apache.org/licenses/LICENSE-2.0
- Quelle: https://github.com/google/draco
